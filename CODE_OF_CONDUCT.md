# Code of Conduct

Leaflet Polydraw is maintained as an open source project for people building map
and GIS tools. Contributions, bug reports, feature ideas, and technical
discussion should stay respectful, specific, and useful.

## Expected Behavior

- Be considerate and professional when discussing issues, pull requests, and
  design decisions.
- Assume good intent, but ask for clarification when something is unclear.
- Keep criticism focused on the code, documentation, behavior, or technical
  tradeoff.
- Respect that maintainers may decline changes or defer work based on project
  scope, release timing, or maintenance cost.

## Unacceptable Behavior

- Harassment, insults, threats, or discriminatory language.
- Personal attacks or repeated hostile comments.
- Publishing private information without permission.
- Spam, off-topic promotion, or behavior that disrupts project maintenance.

## Reporting

If you see behavior that does not fit this code of conduct, contact the project
maintainer through the repository issue tracker or the maintainer profile on
GitHub. Reports will be reviewed by the maintainer and handled at their
discretion.

## Enforcement

The maintainer may edit or remove comments, close issues or pull requests, block
users, or take other reasonable steps to keep the project productive and safe.
